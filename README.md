# ⚡ 跨设备传输 - 极速直连互联系统

采用全新定制现代高颜值 UI 界面，专门针对**工厂工控机、单账号微信无法双登、无网脱网、手机与电脑高频互传**打造的免安装互联传输系统。

---

## 🌟 核心特色与用户体验

1. **定制级高审美 UI（1:1 像素级还原）**：
   - 顶部呼吸指示灯：`● 服务运行中`。
   - 三模式胶囊滑动切换：`WiFi 局域网` | `网线直连` | `公网远程`。
   - 电脑端：大号虚线拖拽卡片，支持批量文件与图片拖入。
   - 手机端：自适应折叠为 `选取相册／文件` 和 `实时拍照上传` 两个移动端大按钮。
   - 文字快传：支持直接输入或粘贴文字发送，手机与电脑均可一键**复制**或**下载保存为 .txt 文件**。
   - 左右双卡片双向直下：
     - **左侧：我接收的文件**（支持电脑与手机在页面上直接点击【下载】保存，文字支持【复制】+【下载】）。
     - **右侧：待分享的文件**（支持页面直接点击【添加分享文件】与【下载】保存，带阅后即焚自动清理）。
2. **对方设备“三零原则”**：
   - **零安装**：对方电脑或手机不需要下载任何客户端或驱动。
   - **零登录**：不需要登录微信、QQ 或网盘账号，杜绝隐私泄露与账号互斥。
   - **零残留**：对方打开浏览器即可收发，传完关闭浏览器网页，零注册表和垃圾残留。
3. **三大网络自适应**：
   - 📡 **WiFi 局域网**：同 WiFi 或电脑开热点，全速无线对传（30~80 MB/s）。
   - 🔌 **网线直连 (工厂专用)**：一根网线直接对插，脱网跑满千兆网速（~100 MB/s+）。
   - 🌐 **公网远程**：自动识别本机最新 cpolar 穿透域名，全国任意城市点开即传。

---

## 🚀 启动与使用方式

- **方式一（本地直接运行）**：
  双击运行当前目录下的 **`启动软件.bat`**，点击“打开高颜值传输界面”即可在浏览器中开启 UI。
- **方式二（打包成单文件 EXE 随身带）**：
  双击运行 **`一键打包成独立EXE.bat`**，稍等数十秒即可在 `dist` 文件夹下生成独立的 **`跨设备传输.exe`**，插在 U 盘随插随用！
